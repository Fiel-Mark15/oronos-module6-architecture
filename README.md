## Project Overview
The Library Management System is a proposed web-based application that
allows a school library to manage its book records and borrowing
transactions electronically. It replaces manual logbooks with a
digital system that librarians and students can access through a
web interface.

## Problem Statement
The library currently records borrowed and returned books using
handwritten logbooks. This process is slow, prone to human error, and
makes it difficult to track which books are available, overdue, or
already borrowed. There is no easy way to search for a book's
availability without physically checking the shelves or logs.

## Target Users
- Students (borrowers)
- Librarian (system administrator)

## Main Features
1. Login for students and librarian
2. Search for a book by title or author
3. Borrow a book
4. Return a book
5. Generate a report of borrowed and overdue books

## Proposed Technology Stack
- Frontend: Vue.js
- Backend: Node.js and Express
- Database: MongoDB Atlas Free
- Version Control: Git and GitHub
